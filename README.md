# Контрольная работа №1 по Фронтенд и бэкенд разработке

---

## Практическая №1: CSS-препроцессоры

**Цель:** Освоить SASS для стилизации.

**Что сделано:**
- Карточки товаров (кофейня) на SASS
- Переменные (`$primary`, `$accent`, `$disabled`)
- Миксин `@mixin button($color)`
- 3 карточки с разными товарами

---

## Практические №2-3: Backend API + Postman

**Цель:** Создать REST API и протестировать его.

**Что сделано:**
- Express сервер с CRUD для товаров
- Эндпоинты: GET, GET/:id, POST, PATCH, DELETE
- Начальные данные (5 товаров)
- Тестирование в Postman всех запросов
- Работа с внешним API (TheMealDB)

**Запуск сервера:**
`cd praktika2`
`node app.js`

---

## Практические №4-5: React + Express + Swagger
**Цель**: Связать фронтенд с бэкендом и задокументировать API.

**Что сделано:**
- Backend: Express + CORS + nanoid
- Frontend: React + axios + компоненты
- CRUD: создание, чтение, обновление, удаление товаров
- Swagger: полная документация API (схемы, эндпоинты, примеры)

### Терминал 1 (сервер)
`cd server`  
`node app.js`

### Терминал 2 (клиент)
`cd client`  
`npm start`
